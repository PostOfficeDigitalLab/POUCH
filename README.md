# POUCH

POUCH is a PODLAB tool for converting ASC_SOP metadata in ALE files into per-clip CDL files.

## Download

[Download for Mac — Apple Silicon & Intel](https://github.com/PostOfficeDigitalLab/POUCH/releases/latest/download/POUCH-macOS-universal.zip)

Extract the ZIP and move POUCH.app to Applications. Release notes list the version and compatibility details.

[Release notes and older versions](https://github.com/PostOfficeDigitalLab/POUCH/releases) · [PODLAB](https://podlab.tv)

This repository contains distribution documentation and release assets. Application source code is not included.
