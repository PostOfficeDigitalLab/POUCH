# POUCH

POUCH is a PODLAB tool for converting ASC_SOP metadata in ALE files into per-clip CDL files.

## Download

[Download the latest macOS release](https://github.com/PostOfficeDigitalLab/POUCH/releases/latest)

Apple Silicon and Intel builds are included. Download the app ZIP from Releases, extract it, and move POUCH.app to Applications. Release notes include the version, declared minimum macOS version, and SHA-256 checksum.

## About

[PODLAB website](https://podlab.tv)

This repository contains distribution documentation and release assets. Application source code is not included.
